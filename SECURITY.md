# Security Policy

## Supported Versions

We actively support and maintain the latest version of this project.

| Version | Supported |
|---------|-----------|
| Latest  | ✅ Yes     |
| Older Versions | ❌ No |

---

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

⚠️ Do NOT create a public GitHub issue for security vulnerabilities.

Instead, please send a detailed report to:

📧 Email: aharikrishnan2024@gmail.com  
📌 Subject Line: "Security Vulnerability Report – [Project Name]"

---

### Please Include the Following Details:

- Description of the vulnerability
- Steps to reproduce the issue
- Potential impact
- Screenshots or proof-of-concept (if applicable)
- Suggested mitigation (optional)

---

## Response Timeline

- 📩 Initial response: Within 48 hours  
- 🔍 Investigation and verification: 3–7 working days  
- 🛠️ Fix and patch release: As soon as possible  

We appreciate responsible disclosure and will work promptly to resolve verified issues.

---

## Responsible Disclosure

Please do not publicly disclose security issues until they have been investigated and resolved.

We value the security of our users and contributors and appreciate your cooperation.
